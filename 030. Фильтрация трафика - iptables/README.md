### Задание
1. реализовать knocking port
- centralRouter может попасть на ssh inetrRouter через knock скрипт  
    пример в материалах.
2. добавить inetRouter2, который виден(маршрутизируется (host-only тип сети для виртуалки)) с хоста или форвардится порт через локалхост.
3. запустить nginx на centralServer.
4. пробросить 80й порт на inetRouter2 8080.
5. дефолт в инет оставить через inetRouter.
### Результат
- Для создания машин и запуска плейбука нужно выполнить:  `vagrant up`.   
- Для подключения с centralRouter к inetRouter выполните: 
```bash
for x in 8881 7777 9991; do nmap -Pn --max-retries 0 -p $x 192.168.255.1; done
```

После этого можно подключаться (ключ в домашней директории пользователя root):  
```bash
ssh root@192.168.255.1 -i ~/.ssh/inetRouter_key
```
- Для проверки, что проброс портов работает, выполните: `curl http://192.168.57.10:8080`
