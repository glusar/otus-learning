# Подготовка инфраструктуры

Выполняется один раз перед созданием ВМ.

| Объект | Параметры |
|---|---|
| Proxmox | узел pve, 192.168.1.101, хранилище kingston |
| LAN | 192.168.1.0/24, роутер 192.168.1.1 |
| ПК администратора | 192.168.1.100 |
| DNS | 192.168.1.111 |
| DMZ | vmbr1, 172.16.10.0/24 |
| Внутренняя сеть | vmbr2, 10.20.0.0/24 |
| Шаблон | 9001 |
| Рабочие ВМ | 121–124, пул otus-nextcloud |

Порядок подготовки:

1. Создать мосты и маршрутизацию по [PROXMOX_NETWORK.md](PROXMOX_NETWORK.md).
2. Создать пользователя, роли, пул и API-токен по [PROXMOX_API.md](PROXMOX_API.md).
3. Настроить маршрут роутера и DNS по [ROUTER_DNS.md](ROUTER_DNS.md).
4. Собрать шаблон по [image-build](../image-build/README.md).
5. Создать рабочие ВМ по [OpenTofu](../docs/OPENTOFU.md).
