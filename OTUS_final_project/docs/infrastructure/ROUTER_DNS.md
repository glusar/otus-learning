# Маршрут роутера и DNS

В интерфейсе домашнего роутера добавляем статический IPv4-маршрут:

| Поле | Значение |
|---|---|
| Сеть назначения | 172.16.10.0 |
| Маска | 255.255.255.0 |
| Шлюз | 192.168.1.101 |
| Интерфейс | LAN |

В DNS на 192.168.1.111 открываем пользовательские правила
фильтрации и добавляем A запись:

```text
nextcloud.otus.lan 172.16.10.10
```

На ПК администратора должен использоваться этот DNS-сервер. Внутри стенда Ansible
добавляет собственную запись nextcloud.otus.lan на внутренний адрес
proxy 10.20.0.10 для HTTPS-проверок и обращений сервисов.

После развёртывания проверяем с ПК:

```bash
getent ahostsv4 nextcloud.otus.lan
ip -4 route get 172.16.10.10
```

Ожидаются адрес 172.16.10.10 и маршрут через LAN.
Nextcloud открывается по https://nextcloud.otus.lan,
Grafana — по https://172.16.10.10:8443/grafana/,
ntfy — по https://172.16.10.10:8444/otus-alerts.
