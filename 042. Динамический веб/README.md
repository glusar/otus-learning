### Динамический веб
### Задание
Вариант стенда: - nginx + php-fpm (wordpress) + python (django) + js  
Реализация: деплой через docker-compose.  

Требования:  
- vagrant стенд с проброшенными на локалхост портами
- каждый порт на свой сайт
- через nginx

### Результат
1. Машина с приложениями поднимается командой `vagrant up`
2. Для проверки работы приложений переходим по ссылкам:  
	- http://localhost:8081/
	- http://localhost:8082/
	- http://localhost:8083/
