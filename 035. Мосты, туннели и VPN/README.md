### Задание
1) Настроить VPN между двумя ВМ в tun/tap режимах, замерить скорость в туннелях, сделать вывод об отличающихся показателях
2) Поднять RAS на базе OpenVPN с клиентскими сертификатами, подключиться с локальной машины на ВМ

### Результат
1. Все необходимое находится в директории `vagrant_vpn_tuntap`. Для создания машин и запуска плейбука нужно выполнить:  `vagrant up`
	- Для режима tap достаточно запустить vagrantfile или выполнить плейбук:
		```bash
		ansible-playbook ansible/provision.yml -i ansible/hosts
		```
	- Для режима tun нужно запустить плейбук и указать переменную:  
		```bash
		ansible-playbook ansible/provision.yml -i ansible/hosts -e "tun_enable=true"
		```

2. Все необходимое находится в директории `vagrant_vpn_ras`. Для создания и запуска плейбука нужно выполнить: `vagrant up`. После отработки плейбука, в директории выше `ansible` будут созданы файлы, включая кофниг файл клиента. Для запуска openvpn выполните:  
	```bash
	sudo openvpn --config ./client.conf
	```
