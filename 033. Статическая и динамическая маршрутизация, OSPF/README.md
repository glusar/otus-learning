### Задание
1. Поднять три виртуалки
2. Объединить их разными vlan
- поднять OSPF между машинами на базе Quagga;
- изобразить ассиметричный роутинг;
- сделать один из линков "дорогим", но что бы при этом роутинг был симметричным.
### Результат
- Для создания машин и запуска плейбука нужно выполнить:  `vagrant up`
- Для ассиметричного роутинга просто запустите плейбук  
- Для симметричного роутинга запустите плейбук, указав переменную:  
```bash
ansible-playbook -i ansible/hosts -l all ansible/provision.yml -e "host_key_checking=false" -e "symmetric_routing=true"
```
